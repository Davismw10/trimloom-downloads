# Trimloom 2.0: descarregar

Editor de cortes de vídeo para gravações de aulas, reuniões e podcasts. Marque os trechos que quer manter e exporte em segundos: o corte é feito sem perder qualidade. Funciona sem Internet e sem conta; os seus ficheiros ficam no seu computador e o original nunca é alterado.

**Novidade da 2.0:** uma gravação feita em várias partes abre-se de uma só vez e fica numa linha de tempo contínua. Um corte pode começar no fim do primeiro ficheiro e acabar no início do segundo, e sai num só ficheiro, sem corte visível.

## Descarregar

Vá a **[Releases](../../releases/latest)** e descarregue o ficheiro para o seu sistema:

- **Windows (64 bits):** `Trimloom-…-windows-x64.exe`
- **macOS (Apple Silicon: M1, M2, M3, M4):** `Trimloom-…-mac-arm64.dmg`

## Instalar

**Windows**

1. Abra o ficheiro descarregado e siga o instalador.
2. Se o Windows mostrar "O Windows protegeu o seu PC", carregue em **Mais informações → Executar assim mesmo**. A aplicação ainda não tem assinatura digital.

**macOS**

1. Abra o `.dmg` e arraste o Trimloom para a pasta Aplicações.
2. Na primeira vez, clique com o botão direito no Trimloom e escolha **Abrir**. A aplicação não é assinada pela Apple.

## Como usar

1. Abra uma gravação (ou várias, de uma vez) ou largue-a na janela.
2. Prima **I** e **O** para marcar o início e o fim de cada trecho, ou **M** para deixar marcadores.
3. Prima **P** para ver só o resultado antes de exportar.
4. Prima **Ctrl/⌘ + E** e exporte em vídeo, só áudio ou vídeo vertical 9:16.

Se as gravações tiverem formatos diferentes, a aplicação avisa e converte só o ficheiro diferente: demora mais, mas o resultado fica correto.
